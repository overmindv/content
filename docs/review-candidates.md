# Источник кандидатов для ревью

`content` хранит назначения и голоса. `users` отвечает за состояние аккаунта и
права пользователя. Тематический рейтинг не является правом рецензировать.
Таблица лидеров практики не подходит для выдачи прав.

## Внутренний API

Укажи `CONTENT_REVIEW_CANDIDATES_URL` и отдельный
`CONTENT_REVIEW_CANDIDATES_TOKEN`. Без обеих переменных фоновая проверка
выключена. За пределами loopback требуется HTTPS.

Запрос: `POST /v1/review-candidates`, заголовок `Authorization: Bearer <token>`.
Тело содержит:

- `topic_id`: UUID темы. Если у материала несколько тем, для новой ревизии
  выбирается первая по UUID. После первой успешной проверки тема закрепляется.
- `proposal_author_id` и `material_owner_id`: UUID автора правки и владельца
  материала. Владелец может отсутствовать у старых материалов.
- `assignee_ids`: до трех UUID назначенных участников.

Ответ `200`: `topic_id`, `ranked_candidate_ids` и `eligible_assignee_ids`. Оба
списка обязательны; пустой результат передается как `[]`. UUID в списках
канонические, без повторов.

`ranked_candidate_ids` содержит до 64 доступных пользователей с действующим
правом рецензировать тему. Порядок: рейтинг по убыванию, при равенстве UUID по
возрастанию. Допустимый владелец материала должен входить в список, даже если
иначе не попал бы в лимит. Автор правки не назначается.

`eligible_assignee_ids` содержит только подтвержденных пользователей из
`assignee_ids`. Потеря права на тему или деактивация аккаунта исключает
пользователя из обоих списков. При недоступности ролей или рейтинга источник
должен вернуть ошибку, а не успешный ответ с пустыми списками.

## Повторная проверка

Новая ревизия и разногласие двух рецензентов ставят проверку в очередь.
Открытые ревизии повторно проверяются не чаще одного раза в 10 секунд, кроме
разногласий. Успешная проверка продлевает допуск на 30 секунд. Если подтвердить
права не удалось, по истечении допуска назначенный рецензент теряет доступ, а
его голос не может дать действующее одобрение. Подтвержденный отзыв права
исключает назначение сразу при обработке ответа. Старый ответ не может
перезаписать результат новой проверки.

Действующего сервиса, который возвращает права по теме и тематический рейтинг,
пока нет. Компонентный тест использует PostgreSQL и тестовый HTTP-источник.
