# internal/pb/pg

В эту директорию кладутся protobuf-контракты и/или сгенерированные клиенты других сервисов,
с которыми текущий сервис общается по gRPC.

Шаблон:

- `internal/pb/pg/<other-service-name>/` содержит `.proto`, `buf`-модуль или сгенерированные файлы.
- `internal/pkg/service/external/` содержит тонкую обёртку над клиентом другого сервиса.
- `README.md` сервиса описывает, кто владелец контракта и как синхронизировать изменения.
