# Интеграция Bumblebee с Ironhide

Репозиторий Bumblebee пока не содержит приложения. При реализации материала его модель должна хранить только UUID `university_id`, `program_id`, `course_id` и `topic_id`, без копирования названий каталога.

Перед созданием и изменением материала сервис обязан вызвать `POST /v1/validate/binding` внутреннего HTTP API Ironhide. Ответ `{"valid":true}` разрешает сохранение; `false` или ошибка Ironhide запрещают операцию. Клиент следует вынести за интерфейс `CatalogValidator`, чтобы transport и доменная логика не зависели от HTTP.

Для устойчивости запрос должен иметь timeout, а недоступность Ironhide должна приводить к явной ошибке, а не к сохранению непроверенной связки.
